B21 Pro Gray Editor

Load a noprime-patched base (…_noprime10_crcfix.bin from b21patch.py, or any gray variant — they all have it), choose the gray profile and load compensation, and write a flashable image back out. This tool only does the gray part; the no-name full-heat (noprime) part must already be in the base, or tagless rolls still won't print. For 3.09–3.11 it builds the RFID-aware firmware (genuine NIIMBOT rolls keep the stock curve, no-name / tagless rolls get your curve); 3.12/3.13 get an always-spread curve. Header byte-identical, body CRC re-solved, nothing uploaded.

Gray curve — increment cL

Darkness tracks the cumulative sum Σ(c0…cL) — the splitter is thermometric, so a level-L dot fires in all planes 0…L. Constant increments give an even darkness ramp. L15 is full black — left alone.

Load compensation

×2.00
Scales the 7 per-level load factors (k0 = 0.32 kept). Higher = dense / full-width fields print darker, closer to thin dithered areas. ×2 is the current best on no-name paper. 1-bit mode is not affected.

3.09–3.11 build the two code caves (clear the roll type on a tagless read, add the per-level delta at the gray setup return) and keep L15 + the 1-bit path; 3.12/3.13 patch the inline constants (no cave room).
